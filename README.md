# MarketPulse

A modern financial intelligence dashboard built with Django.

MarketPulse aggregates financial and economic data from multiple third-party REST APIs into a single responsive web application. The project focuses on backend engineering, service-layer architecture, data aggregation, and dashboard development rather than trading or portfolio management.

---

## Features

- Financial news aggregation
- Cryptocurrency market data
- Stock market indices
- Currency exchange rates
- Commodity prices
- Weather information for major financial cities
- Economic calendar
- Central bank interest rates
- Inflation data
- Country economic snapshots
- Interactive charts and dashboards
- Responsive Bootstrap 5 interface

## Installation

Clone the repository:

```bash
git clone https://github.com/Kgothatso-create/marketpulse.git
```

Navigate to the project directory:

```bash
cd marketpulse
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the virtual environment.

Install dependencies:

```bash
pip install -r requirements.txt
```

Run migrations:

```bash
python manage.py migrate
```

Start the development server:

```bash
python manage.py runserver
```

Visit:

```
http://127.0.0.1:8000/
```
